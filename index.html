추천 취향

기본 선호 장르

선택한 장르는 이 브라우저에 저장되며, 다음 방문 때 기본 추천에 사용돼요.

서비스 정보

  • 작품 데이터 Kitsu 공개 API에서 작품 정보, 예고편 ID, 시즌·관련 작품 정보를 가져와요. 등록된 예고편은 YouTube에서 재생해요.
  • 추천 방식 시놉시스의 TF-IDF 벡터와 장르를 코사인 유사도로 비교하는 콘텐츠 기반 추천이에요. 생성형 AI나 학습형 모델은 사용하지 않아요. 로그인하면 찜 작품과 선호 장르도 반영해요.
  • 저장 정보 계정과 찜 목록은 서버 데이터베이스에 저장하고, 테마와 기본 선호 장르는 현재 브라우저에 저장해요.

AI 큐레이터에게 물어보기

원하는 애니를 바로 물어보거나 대화로 취향을 좁혀보세요. 등록된 작품만 추천하며, 로그인하면 대화 기록을 계정에 저장합니다.

나만의 애니 캐릭터 만들기

캐릭터 설정은 설정에서 선택한 AI가 만들고, 이미지는 GPT 또는 Gemini가 생성해요. Claude는 이미지 생성 기능을 제공하지 않아 이미지 생성에 사용할 수 없어요. 각 제공자의 API 키와 요금이 적용되며 이미지는 서버에 저장하지 않아요.

Claude는 캐릭터 설정 생성에 사용할 수 있지만 이미지는 만들 수 없어요.
