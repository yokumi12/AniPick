# AniPick 애니메이션 탐색

AniPick은 장르별 애니메이션을 탐색하고, 작품 정보를 확인하며, 계정별로 즐겨찾기를 저장할 수 있는 프로토타입입니다. 작품 이미지가 강조된 헤더, 포스터 카드, 간결한 메타데이터를 사용하는 데스크톱 애니메이션/OTT 카탈로그 UI에서 영감을 얻었습니다. 포스터나 카드를 선택하면 상세 화면이 열립니다. 해당 작품의 Jikan 데이터가 있으면 예고편을 미리 볼 수 있고, 현재 합법적으로 시청할 수 있는 서비스를 JustWatch에서 검색할 수 있습니다. 본 서비스는 에피소드를 스트리밍하지 않습니다.

## 프로젝트 구조

```text
AniPick/
├── server.py                 # HTTP 서버와 API
├── index.html                # 웹 화면
├── database.py               # MySQL 접근과 스키마
├── recommender.py             # 콘텐츠 기반 추천
├── airing_schedule.py         # 주간 방영 일정
├── character_info.py          # 등장 캐릭터 정보
├── api_key_store.py           # 계정별 AI API 키 저장
├── ai_*.py                    # AI 추천·요약·태그·캐릭터 기능
├── data/                      # 공개 애니메이션 카탈로그 JSON
├── scripts/                   # DB 설정과 카탈로그 수집
│   └── aws/                   # AWS 배포 스크립트와 인프라 템플릿
├── tests/                     # 자동화 테스트
├── Dockerfile
├── compose.yaml
├── requirements.txt
└── README.md
```

## 배포 서비스

- **서비스:** [AniPick 웹 앱](https://d1er2zzc6dmy3u.cloudfront.net)
- **상태 확인:** [헬스 체크](https://d1er2zzc6dmy3u.cloudfront.net/health)
- **구성:** CloudFront → API Gateway HTTP API → 내부 ALB → EC2 앱 서버 → 비공개 RDS MySQL

AWS 실습 환경에 따라 서버가 중지된 동안에는 서비스 링크에 접속할 수 없습니다.

## 앱 실행

로컬 개발에는 Python 3.10 이상과 MySQL 8.0이 필요합니다. 로컬 개발과 운영 환경 모두 MySQL을 사용하며, SQLite 대체 기능은 제공하지 않습니다.

아래 안내에 따라 로컬 MySQL 데이터베이스를 설정한 다음, 이 폴더에서 PowerShell 터미널을 열고 실행합니다.

```powershell
python server.py
```

그런 다음 <http://127.0.0.1:8000>을 엽니다. 로컬 서버를 중지하려면 `Ctrl+C`를 누릅니다. 서버가 시작될 때 `data/anime.json`의 카탈로그 데이터가 MySQL로 가져와집니다.

사용자는 중복되지 않는 아이디(영문자, 숫자, 밑줄로 구성된 4~20자)와 8자 이상의 비밀번호로 가입하고 로그인하여 비공개 즐겨찾기 목록을 저장할 수 있습니다. 아이디는 대소문자를 구분하지 않습니다. 카탈로그 탐색과 장르 추천은 공개 기능입니다. 비밀번호는 평문이 아닌 PBKDF2-HMAC-SHA256 해시로 저장됩니다. 세션에는 무작위 HttpOnly 쿠키를 사용하며, 즐겨찾기를 변경할 때는 CSRF 토큰을 확인합니다. 설정 페이지에서는 현재 로그인 상태를 확인하고 브라우저에 저장되는 라이트/다크 테마와 선호 장르를 설정할 수 있습니다. 로그인하지 않은 상태에서 헤더의 계정 아이콘을 누르면 로그인 화면이 열리고, 로그인한 상태에서는 설정·로그아웃·계정 삭제 메뉴가 열립니다. 서비스 안내에서 Kitsu 데이터 출처와 장르 중복을 기준으로 하는 기본 추천 방식을 설명합니다.

고정 헤더에는 탐색 메뉴, 작품 제목 검색, 라이트/다크 테마 전환, 설정, 계정 메뉴가 있습니다. 탐색 메뉴에서는 홈 추천, 요일별 방영 일정, 전체 카탈로그, 계정 즐겨찾기, 평점이 높은 작품, 최신 작품, 설정으로 이동할 수 있습니다. 모바일 하단 메뉴에는 홈, 방영 일정, 즐겨찾기, 바로가기, 검색이 있습니다. 카탈로그에는 인기도 지표나 업데이트 시각이 없으므로, 작품 탐색 바로가기는 대신 제공되는 평점과 공개 연도를 사용합니다. AniPick은 전체 에피소드를 재생하지 않으며 시청 기록도 저장하지 않습니다.

### 로컬 MySQL 서버 설정

이 폴더에서 Python 의존성을 설치하고 로컬 MySQL 데이터베이스를 설정합니다.

```powershell
python -m pip install -r requirements.txt
python scripts\setup_mysql.py
python server.py
```

설정 명령은 MySQL 관리자 비밀번호를 입력받으며, 입력 내용은 화면에 표시되지 않습니다. 이 명령은 `anipick` 데이터베이스를 만들고, 임의로 생성한 비밀번호를 사용하는 로컬 전용 앱 계정을 만든 뒤 해당 계정의 접속을 확인하고 연결 설정을 `.env`에 기록합니다. `.env`는 Git에서 제외됩니다. 데이터베이스 비밀번호를 소스 코드에 붙여넣거나 `.env`를 커밋하지 마세요. 기존 로컬 SQLite 파일이 있더라도 읽거나 마이그레이션하지 않습니다. 카탈로그 데이터는 `data/anime.json`에서 다시 가져오며, 사용자는 MySQL에서 다시 가입해야 합니다.

앱이 MySQL을 사용 중인지 확인하려면 서버 시작 메시지에 `MySQL database: 127.0.0.1:3306/anipick`이 표시되는지 확인합니다. MySQL Workbench에서 `127.0.0.1:3306`에 연결하면 `anipick` 스키마에 다음 11개 테이블이 있어야 합니다.

`anime`, `genre`, `anime_genre`, `ai_synopsis_cache`, `ai_tags_cache`, `user_account`, `user_session`, `user_ai_api_key`, `favorite`, `ai_curator_conversation`, `ai_curator_message`

**AWS 배포:** CloudFormation 배포는 EC2, RDS MySQL, 내부 ALB, API Gateway VPC Link, CloudFront로 구성합니다. 기존 `anipick-ec2-role` 인스턴스 프로파일을 사용하며 IAM 리소스는 생성하지 않습니다. CloudFront는 AWS 관리형 `CachingDisabled` 및 `AllViewerExceptHostHeader` 정책을 사용합니다. 배포 스크립트와 인프라 템플릿은 [scripts/aws](./scripts/aws/)에서 확인할 수 있습니다. 이 구성은 EC2 단독 배포와 다른 AWS 비용을 발생시킵니다.

**운영 환경 변수:** 로컬에서는 위 설정 도구가 `.env`를 구성합니다. AWS에서는 호스팅 환경 또는 시크릿 관리자에 다음 설정을 구성하세요.

`ANIPICK_MYSQL_HOST`, `ANIPICK_MYSQL_PORT`, `ANIPICK_MYSQL_USER`, `ANIPICK_MYSQL_PASSWORD`, `ANIPICK_MYSQL_DATABASE`

이 값을 절대 커밋하지 마세요. HTTPS 설정이 완료된 운영 환경에서는 세션 쿠키에 `Secure` 속성을 적용하도록 `ANIPICK_ENV=production`을 설정합니다.

## 테스트 실행

단위 테스트 전체를 실행하려면 다음 명령을 사용합니다.

```powershell
python -m unittest discover -s tests
```

데이터베이스 통합 테스트에는 이름이 `_test`로 끝나는 별도의 MySQL 스키마가 필요하며, `ANIPICK_TEST_MYSQL_DATABASE`로 지정합니다. 해당 테스트 스키마에만 권한이 있는 MySQL 계정을 사용하세요. 개발 또는 운영용 `anipick` 스키마를 테스트에 사용하면 안 됩니다.

## 애니메이션 카탈로그 새로고침

데이터 수집기는 공개 Kitsu API를 사용하고 가져온 스냅샷을 `data/anime.json`에 저장합니다.

```powershell
python scripts\fetch_anime.py --pages 4
```

각 페이지에는 최대 20개 작품이 포함되므로, 4개 페이지를 요청하면 최대 80개 작품을 가져옵니다. 데이터 수집기는 장르 관계 정보를 포함하고 페이지 요청 사이에 대기합니다. 목록 API가 관련 작품을 제공하지 않는 경우에도 시즌 연결 정보를 유지할 수 있도록, 수집 대상 작품의 관계 상세 정보도 요청합니다. 새 카탈로그를 가져온 다음 `python server.py`를 다시 실행하면 변경된 카탈로그를 가져옵니다.

카탈로그에는 제목, 장르, 공개 연도, 에피소드 수, 평점, 줄거리, 포스터 이미지 URL, Kitsu의 YouTube 예고편 ID, 전편·후속편·외전 등의 관련 작품 정보가 포함됩니다. 상세 화면에는 등록된 YouTube 예고편이 있으면 삽입해 보여주고, Kitsu의 관련 시즌으로 연결합니다. 전체 작품 목록이 아니라 인기 작품을 일부 수록한 샘플입니다. 장르는 한국어 이름으로 표시됩니다. 저장 전에 Ecchi/Hentai/Erotica, 성인 콘텐츠 카테고리 또는 R18 등급으로 표시된 작품은 제외합니다. 일반 R 등급만으로는 제외하지 않습니다. 장르가 하나도 없는 작품도 제외하여 모든 추천 대상에 장르 정보가 있도록 합니다. 추천 기능은 생성형 AI 모델을 사용하는 대신 로컬 TF-IDF/코사인 유사도 기반으로 줄거리 표현과 장르의 중복도를 비교합니다.

## 콘텐츠 기반 추천

로컬 `recommender.py` 모듈은 Kitsu 줄거리와 장르 이름을 사용해 TF-IDF 벡터를 만들고 메모리에 캐시합니다. 이 기능은 다음에 사용됩니다.

- 각 작품 상세 화면에서 줄거리와 장르 유사도를 기준으로 비슷한 애니메이션을 정렬합니다.
- 작품 제목 검색 결과가 없을 때 선택적으로 자연어식 검색 대체 기능을 제공합니다. `힐링`, `전투`와 같은 한국어 분위기·주제 단서는 카탈로그 장르와 줄거리 키워드에 대응합니다. 고정 키워드 매핑을 사용하며 LLM은 사용하지 않습니다.
- 로그인한 사용자의 즐겨찾기 작품과 선호 장르를 바탕으로 개인화 순위를 제공합니다. 같은 선호도 점수로 해당 주의 방영 작품도 정렬할 수 있습니다.

이 기능들은 AI 제공업체 키가 필요하지 않으며 생성형 AI 서비스를 호출하지 않습니다. 유사도와 순위는 로컬 카탈로그에서 계산하므로, 영어로 작성된 원본 줄거리와 작은 카탈로그 규모에 따라 결과가 제한될 수 있습니다.

### AI 한국어 줄거리 요약

영어 원문 줄거리는 있지만 카탈로그에 한국어 줄거리가 없는 작품의 상세 화면에서 **AI로 한국어 줄거리 요약**을 선택합니다. 선택한 AI 제공업체는 원문 줄거리만을 바탕으로 스포일러를 주의한 짧은 요약을 만듭니다. 생성된 요약은 작품과 원문 텍스트별로 앱 데이터베이스에 캐시되므로 같은 요약을 다시 열어도 제공업체를 다시 호출하지 않습니다. 원문이 변경되면 캐시된 결과는 무효화됩니다. 이 기능은 유료 API를 호출하며 클라이언트 IP당 15분에 8회로 제한됩니다. 카탈로그에 등록된 한국어 줄거리는 변경되지 않습니다.

### AI 테마·분위기 태그

카탈로그 작품의 상세 화면에서 **줄거리에서 AI 태그 만들기**를 선택합니다. AI는 통제된 한국어 분위기·주제 어휘에서만 태그를 선택하며, 카탈로그 원본 장르는 덮어쓰지 않습니다. 태그는 작품과 원문 줄거리별로 저장되고 상세 화면에 표시됩니다. 자연어 추천 문맥에 포함되며 로컬 유사도 및 검색의 보조 신호로도 사용됩니다. 첫 생성은 요청에 따라 실행되는 유료 API 호출이고, 저장된 태그는 다음 요청에서 재사용됩니다. 클라이언트 IP당 15분에 8회로 제한됩니다.

### AI 큐레이터 및 추천

홈 화면에서 AI 추천 기능은 대화형 큐레이터 하나로 제공합니다. 선호 조건에 맞는 애니메이션을 바로 요청하면 최대 5개 작품을 추천하며, 대화를 이어가며 조건을 구체화할 수도 있습니다. 추천 결과는 로컬 카탈로그에 있는 작품으로 제한됩니다. 대화 한 번마다 유료 API를 호출하며, 클라이언트 IP당 15분에 8개 메시지로 제한됩니다. 설정에서 선택한 제공업체(또는 `.env`의 기본값)를 사용하며, 해당 제공업체의 API 키가 필요합니다. 로그인하지 않은 사용자의 대화 상태는 현재 페이지에만 저장됩니다. 로그인 사용자는 계정당 최대 20개의 대화를 저장할 수 있으며, 각 대화에는 최근 메시지 최대 40개가 보관됩니다. 저장된 대화는 큐레이터 창의 대화 선택 메뉴에서 확인할 수 있으며, 계정 세션과 CSRF 검사를 통해 보호됩니다.

### 오리지널 캐릭터 만들기

홈 화면에서 큐레이터와 오리지널 캐릭터 만들기를 각각 별도의 창으로 엽니다. 캐릭터 만들기는 설정에서 선택한 AI 제공업체로 이름, 역할, 외모, 성격, 능력, 배경, 짧은 대사를 생성하고, 이미지 제공업체로 PNG 초상화를 만듭니다. 이미지 제공업체는 GPT(OpenAI) 또는 Gemini 중에서 선택할 수 있으며, Claude는 이미지 생성 기능이 없어 사용할 수 없다는 점을 창에서 미리 안내합니다. 이미지 생성은 클라이언트 IP당 15분에 3회로 제한되며, 선택한 제공업체의 요금이 발생할 수 있습니다. 이미지 생성에 실패해도 텍스트 프로필은 계속 표시되며 이미지 요청만 다시 시도할 수 있습니다.

캐릭터 이미지 생성은 GPT(OpenAI)와 Gemini 중 제공자를 선택할 수 있습니다. 로그인한 사용자는 설정의 AI 제공자 영역에 해당 제공자의 API 키를 저장할 수 있습니다. Claude는 텍스트로 캐릭터 설정을 만들 수 있지만 이미지 생성 API를 제공하지 않아 이미지 생성 제공자로 사용할 수 없습니다. 기본 모델은 OpenAI의 `gpt-image-2.5-sunburst`와 Gemini의 `gemini-nano-banana-2.1`이며, 각각 `ANIPICK_OPENAI_IMAGE_MODEL`과 `ANIPICK_GEMINI_IMAGE_MODEL`로 변경할 수 있습니다. `gpt-image-1`은 2026년 10월 23일 지원이 종료됐으므로 해당 모델을 지정한 환경 변수는 삭제하거나 지원 모델로 변경해야 합니다. 생성된 이미지는 미리보기와 다운로드를 위해 브라우저로 전송되며 데이터베이스나 서버에 저장되지 않습니다. API 키는 브라우저 저장소에 보관하지 마세요.

## 주간 방영 일정

주간 방영 페이지는 AniList 공개 GraphQL API를 사용하는 별도의 읽기 전용 화면입니다. 한국 표준시 기준 요일별로 향후 에피소드를 표시하고, 방영작 제목을 Kitsu 기반 로컬 카탈로그와 대조해 카탈로그에 있는 작품을 표시합니다. 모든 방영작을 자동으로 카탈로그에 추가하지는 않습니다. 제목 검색, 제공되는 장르와 시작 연도 필터링, 인기도·최신 연도·평점·제목·방영 시간순 정렬, 그리드/목록 레이아웃 전환을 지원합니다. 필터를 변경하면 결과와 카탈로그 일치 작품 수가 갱신됩니다. 정렬 및 레이아웃 선택은 브라우저에 저장됩니다. 로컬 샘플 카탈로그에는 작품 68개가 있습니다. 기존 61개에 방영 목록에서 선택한 누락 작품 7개를 추가했습니다. 방영 일정 결과는 메모리에 6시간 동안 캐시되며 AniList 데이터가 갱신되면 결과가 달라질 수 있습니다. 방영 일정 API에 장애가 발생해도 카탈로그 탐색은 계속 이용할 수 있습니다.

### AI로 한국어 캐릭터 정보 보기

애니메이션 상세 화면에서 **등장 캐릭터 불러오기**를 선택합니다. AniPick은 해당 카탈로그 작품을 AniList에서 검색해 캐릭터 이미지, 역할, 출처 링크를 최대 8개까지 보여줍니다. 설정된 AI 제공업체는 AniList가 제공한 캐릭터 이름을 한국어 표시 이름으로 번역하고 설명을 요약합니다. 캐릭터를 식별할 수 있도록 원래 이름도 확인할 수 있습니다. AI가 생성한 한국어 문구는 공식 번역이 아닙니다. 원본 설명이 없는 캐릭터에는 내용을 만들어내지 않고 요약 없이 표시합니다. 이 기능은 AniList 캐릭터 이미지를 보여주며 새 이미지를 생성하지 않습니다.

캐릭터 정보의 이름과 설명을 한국어로 표시하려면 AI 제공업체 API 키가 필요합니다. 로그인한 뒤 설정 페이지의 **AI 제공자** 영역에서 OpenAI, Gemini, Claude 키를 입력하고 계정에 저장할 수 있습니다. 키는 계정별로 MySQL에 암호화해 저장되며 다시 화면에 표시되지 않습니다. 빈 입력란은 기존 키를 유지하고, 제공자별 삭제 버튼으로 계정 키를 제거할 수 있습니다. 로그인 세션과 CSRF 토큰을 확인하며, 저장된 키는 해당 계정의 AI 요청에만 사용됩니다. 로컬에서는 암호화 키를 처음 저장할 때 `.env`에 자동 생성합니다. 운영 환경에서는 `ANIPICK_API_KEY_ENCRYPTION_KEY`를 AWS Secrets Manager 같은 서버 측 시크릿 관리자로 설정해야 계정 키 저장이 활성화됩니다. 이 암호화 키를 잃으면 저장된 계정 키를 복구할 수 없습니다. 기존 서버 환경 변수에 설정된 제공업체 키도 기본 키로 사용할 수 있습니다. 설정 페이지에서 각 브라우저는 키가 설정된 제공업체 중 하나를 선택할 수 있으며, 계정 키가 있으면 서버 기본 키보다 우선합니다. 선택한 제공업체는 캐릭터 정보, 자연어 추천, 한국어 줄거리 요약에 공통으로 적용됩니다.

```dotenv
ANIPICK_AI_PROVIDER=claude
ANTHROPIC_API_KEY=your-claude-api-key
```

OpenAI를 사용하려면 `OPENAI_API_KEY`를, Google Gemini를 사용하려면 `GEMINI_API_KEY`를 추가합니다. 그러면 해당 제공업체도 선택할 수 있습니다. `ANIPICK_AI_PROVIDER`는 서버 기본값이며, 브라우저 설정에서 키가 구성된 제공업체를 선택할 수 있습니다. 모델을 선택적으로 재정의하는 환경 변수는 `ANIPICK_OPENAI_MODEL`, `ANIPICK_GEMINI_MODEL`, `ANIPICK_CLAUDE_MODEL`입니다. 기본 모델은 각각 `gpt-4o-mini`, `gemini-3.8-flash`, `claude-haiku-4-5-20251001`입니다. 사용자가 캐릭터 정보를 요청할 때만 API를 호출하며, 조회 요청은 횟수 제한이 적용됩니다. Gemini 요청은 요청별 저장을 사용하지 않도록 설정한 Google Interactions API를 사용합니다.

번역 결과는 `data/character-cache.json`에 저장됩니다(Git 제외 대상). 캐시 키는 캐릭터 원문과 선택한 제공업체/모델입니다. API 키를 나중에 제거하더라도 캐시 결과를 제공하며, 원문이 바뀌면 새로 번역합니다. 캐시에는 최대 500개 항목을 보관합니다. 제공업체 사용 요금이 발생할 수 있습니다. API 키는 서버에만 보관하며 브라우저로 보내지 않습니다.

AniList 스포일러 블록(`~!...!~`)과 마크업은 설명을 AI 제공업체에 보내거나 화면에 표시하기 전에 제거합니다. 검색 결과는 카탈로그 제목과 시작 연도로 확인합니다. 최대 세 개의 카탈로그 제목으로 조회를 시도하며, 시즌이 일치하지 않는 캐릭터를 표시하는 대신 오류를 반환합니다.

Kitsu는 카탈로그, 예고편 ID, 관련 애니메이션 메타데이터를 제공합니다. 예고편은 YouTube에서 삽입해 보여줍니다. 검토된 ID가 있는 `data/youtube-overrides.json`은 Kitsu 예고편 ID보다 우선하지만, AniPick은 해당 영상이 공식 영상인지 검증하지 않습니다. JustWatch 링크는 작품 제목 검색을 보여주며, 서비스 제공 여부는 지역과 날짜에 따라 달라질 수 있습니다. 가져온 데이터를 배포하거나 교실 프로토타입 이외의 목적으로 사용하기 전에 Kitsu의 최신 이용 약관을 확인하세요. 포스터는 외부 이미지 URL을 사용하며 에피소드 영상은 다운로드하거나 스트리밍하지 않습니다. 한국어 제목 재정의 및 직접 작성한 한국어 줄거리 재정의는 `data/korean-overrides.json`에서 관리합니다. 한국어 제목이 없으면 UI에 카탈로그 제목을 표시하고, 한국어 줄거리가 없으면 Kitsu 줄거리를 원문으로 표시합니다. 한국어 줄거리는 라이선스가 있는 출처에서 가져오거나 직접 간결하게 작성하세요. 앱은 저작권이 있는 줄거리 내용을 기계 번역하여 한국어 번역문인 것처럼 제공하지 않습니다.
